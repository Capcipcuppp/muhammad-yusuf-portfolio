# Muhammad Yusuf Portfolio Collection

Repositori ini berisi 3 konsep portofolio digital yang dibuat berdasarkan CV manual Muhammad Yusuf dan siap untuk dipublish di GitHub Pages.

## Isi repositori
- `index.html` : halaman utama yang menampilkan pilihan tiga desain portofolio
- `cv-manual.html` : halaman CV manual dalam format web
- `cv-manual.md` : CV manual lengkap dalam format teks
- `portfolios/portfolio-1/` : desain modern dan profesional
- `portfolios/portfolio-2/` : desain minimal dan clean
- `portfolios/portfolio-3/` : desain formal corporate
- `.github/workflows/deploy-pages.yml` : workflow untuk deployment otomatis GitHub Pages

## Cara menjalankan secara lokal
```bash
cd portfolio-yusuf
python -m http.server 8000
```
Lalu buka browser ke:
- http://localhost:8000/
- http://localhost:8000/portfolios/portfolio-1/
- http://localhost:8000/portfolios/portfolio-2/
- http://localhost:8000/portfolios/portfolio-3/

## Deployment
Repositori ini sudah dikonfigurasi untuk deployment otomatis GitHub Pages melalui GitHub Actions.

Setelah repo di-push ke GitHub, situs akan tersedia di:
`https://capcipcuppp.github.io/muhammad-yusuf-portfolio/`
